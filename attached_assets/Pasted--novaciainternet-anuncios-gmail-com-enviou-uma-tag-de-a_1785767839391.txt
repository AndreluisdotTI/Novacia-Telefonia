Como usar a tag

Para que o acompanhamento de conversões funcione, você precisa instalar a tag de acompanhamento de conversões, que consiste em uma tag do Google e um snippet de evento. Além disso, é necessário adicionar um código para que o Google Ads só registre uma conversão quando um cliente clicar no link, na imagem ou no botão escolhidos. Se você quiser instalar a tag com o Google Tag Manager, siga estas instruções.

Se alguma das suas páginas da Web foi desenvolvida com a tecnologia AMP, você precisará adicionar tags às versões AMP e HTML. Há instruções para ambas.

gtag('config', 'AW-18096407370');

<!-- Event snippet for Contato via WhatsApp conversion page In your html page, add the snippet and call gtag_report_conversion when someone clicks on the chosen link or button. --> <script> function gtag_report_conversion(url) { var callback = function () { if (typeof(url) != 'undefined') { window.location = url; } }; gtag('event', 'conversion', { 'send_to': 'AW-18096407370/dY87CJWd3rccEMqGhbVD', 'event_callback': callback }); return false; } </script>


Adicione um atributo onclick diretamente ao código do botão ou link que você quer rastrear. O código a ser escolhido dependerá de como o link ou botão aparecerá no seu site: link de texto, botão ou imagem de botão.

Adicione o código a um link de texto: no código abaixo, substitua "http://example.com/your-link" pelo URL do site ou link do telefone e "Fazer download agora" pelo texto do link.

<a onclick="return gtag_report_conversion('http://example.com/your-link');" href="http://example.com/your-link">Fazer download agora</a>

Adicione o código a um botão: esse código mostra como adicionar o recurso de acompanhamento de cliques a um botão usando a tag <button>. Substitua "http://example.com/your-link" pelo URL do seu site.

<button onclick="return gtag_report_conversion('http://example.com/your-link')">Enviar</button>

Adicione o código a uma imagem de botão: no código abaixo, substitua "download_button.gif" pela imagem do seu botão, width e height pelos parâmetros do botão e "http://example.com/your-link" pelo URL do link.

<img src="download_button.gif" alt="Baixar o artigo" width="32" height="32" onclick="return gtag_report_conversion('http://example.com/your-link')" />

Salve as alterações na sua página da Web.
